# Regression inputs

These PDFs are the non-overwriting acceptance set recovered from prior runs.
They are intentionally ignored by Git. Copy them with the exact filenames in
`MANIFEST.sha256`, then run `shasum -a 256 -c MANIFEST.sha256` from this
directory before using their OCR results.

The manifest is provenance for the inputs only. Existing result JSON is not
ground truth and must not be treated as a label source.
